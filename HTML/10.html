01
What is CSS? — Selectors & Rules
Beginner
›
CSS stands for Cascading Style Sheets. You write rules that select HTML elements and apply styles to them.

A rule has two parts: a selector (which element?) and a declaration block (what style?).
style.css
/* selector  { property: value; } */

h1 {

  color: tomato;

  font-size: 32px;

}

p {

  color: #444;

  font-size: 16px;

}

.highlight {          /* class selector */

  background-color: yellow;

}

#main-title {         /* id selector */

  text-decoration: underline;

}

💡 Tip: Use . for classes (reusable) and # for IDs (unique per page).
02
Colors & Backgrounds
Beginner
›
Colors can be written in many formats: named (red), hex (#ff0000), RGB (rgb(255,0,0)) or HSL (hsl(0,100%,50%)).
style.css
.box {

  background-color: #3b82f6;   /* hex */

  color: white;

  padding: 20px;

}

.gradient-box {

  background: linear-gradient(135deg, #6366f1, #ec4899);

  color: white;

  padding: 20px;

}

03
The Box Model — Padding, Margin & Border
Core
›
Every HTML element is a rectangular box. The box model describes its four layers (from inside out):
content → padding → border → margin
style.css
.card {

  width: 200px;

  padding: 20px;          /* space inside */

  border: 2px solid #6366f1;

  margin: 16px;           /* space outside */

  border-radius: 10px;   /* rounded corners */

  box-sizing: border-box; /* include padding in width */

}
Live Preview
Card
padding keeps text away from border. margin keeps cards apart.
Small padding
Less breathing room inside.
💡 Tip: Always set box-sizing: border-box on everything — it makes sizing much more predictable.
04
Typography — Fonts, Size & Spacing
Core
›
Control how text looks with font-family, font-size, font-weight, line-height, and letter-spacing.
style.css
body {

  font-family: 'Georgia', serif;

  font-size: 16px;

  line-height: 1.6;

}

h1 {

  font-size: 2.5rem;     /* rem = relative to root */

  font-weight: 700;

  letter-spacing: -0.03em;

  text-transform: uppercase;

}

05
Flexbox — 1D Layouts
Layout
›
Flexbox arranges items in a single row or column. Use it for navbars, card rows, and centering things.
style.css
.flex-container {

  display: flex;

  justify-content: space-between; /* horizontal */

  align-items: center;            /* vertical */

  gap: 16px;

}

.flex-item {

  flex: 1;   /* grow equally */

}

💡 Tip: justify-content works along the main axis; align-items works along the cross axis.
06
CSS Grid — 2D Layouts
Layout
›
CSS Grid lets you design rows and columns at the same time — perfect for page layouts and dashboards.
style.css
.grid {

  display: grid;

  grid-template-columns: repeat(3, 1fr);

  gap: 12px;

}

.span-2 {

  grid-column: span 2;  /* takes 2 columns */

}

💡 Tip: 1fr means "one fraction of the available space." repeat(3, 1fr) = three equal columns.
07
Transitions & Hover Effects
Core
›
Animate style changes smoothly with transition. Combine with :hover, :focus, or :active pseudo-classes.
style.css
.button {

  background: #6366f1;

  color: white;

  padding: 12px 24px;

  border-radius: 8px;

  transition: all 0.25s ease; /* smooth change */

}

.button:hover {

  background: #4f46e5;

  transform: translateY(-3px);

  box-shadow: 0 8px 20px rgba(99,102,241,.4);

}
Live Preview — hover the buttons!
💡 Tip: transform: translateY(-3px) lifts an element up — a very popular micro-interaction for buttons.
Quick Reference
CSS Cheat Sheet

The most-used properties at a glance.

Text

  • color #333
  • font-size 16px / 1rem
  • font-weight 400 / 700
  • line-height 1.5
  • text-align left/center
  • letter-spacing .05em

Box Model

  • padding top right bot left
  • margin auto (center)
  • border 2px solid red
  • border-radius 8px / 50%
  • box-shadow 0 4px 12px …
  • box-sizing border-box

Layout

  • display flex / grid
  • justify-content center
  • align-items center
  • gap 16px
  • grid-template-cols repeat(3,1fr)
  • flex-wrap wrap

Sizing

  • width 100% / 200px
  • max-width 1200px
  • height 100vh
  • min-height 60px
  • overflow hidden / scroll
  • aspect-ratio 16/9
